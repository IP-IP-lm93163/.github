<h2>静态住宅贵在「固定」这两个字</h2>
<p>地址固定意味着服务商要把这条地址长期留给你，不能再分配给其他人。资源利用率下降，成本自然上升。这是静态比动态贵的最直接原因。</p>
<p>第二个原因是供给。中国香港的住宅资源本来就少，能长期固定提供的更少。稀缺叠加占用成本，价格就有了明显台阶。</p>

<h2>价格构成的四块</h2>
<p>一，带宽成本。香港的国际带宽贵，这部分是硬成本。二，地址占用成本，静态意味着长期占用。三，运维成本，需要有人保证在线与替换。四，渠道加价。</p>
<p>四块里前两块是硬的，后两块有弹性。所以同规格报价的差异，多来自渠道层级与运维水平，而不是资源本身。</p>

<h2>四个档位</h2>
<p>共享动态：价格最低，地址会变，适合短期验证。共享静态：地址固定但多人共用，价格中等偏低。独享静态：一条地址一个人用，价格中等偏高，是长期业务的主力。</p>
<p>原生或双 ISP 独享静态：在独享基础上叠加稀缺属性，价格最高。四个档位之间的价差不是渐进，而是台阶式的。</p>

<p>第三行是多数人的落点。它没有最贵的稀缺属性，但把「固定」和「独享」两个关键点都拿到了，这两个才是长期稳定使用的基础。</p>

<h2>双 ISP 在价格里的位置</h2>
<p>它是在独享静态之上的额外溢价，因为你买的不只是「一个人用」，还有「归属信息更少见」。在香港这种供给紧张的市场，这个溢价幅度往往比欧美更大。</p>
<p>是否值得，判断标准只有一个：业务是否需要这个特征。不需要的话，这笔钱花得没有任何回报。</p>

<h2>共享静态为什么便宜，代价是什么</h2>
<p>因为它把一条地址分给了多人，成本被摊薄。代价有两层：一是性能上会互相影响，有人跑量你就变慢；二是评价上会互相牵连，别人的行为痕迹会累积在这条地址上。</p>
<p>如果业务对稳定性与纯净度不敏感，共享静态是性价比之选。如果有要求，省下的钱会在后面以别的方式还回来。</p>

<h2>长周期与短周期</h2>
<p>香港的长周期折扣一般比较明显，因为服务商希望锁定客户、减少资源闲置。但长周期意味着承诺，中途不用就是纯支出。</p>
<p>建议的节奏是：先用短周期验证，确认可用且需求稳定后，再转长周期谈折扣。反过来先签长约再验证，风险全在自己这边。</p>

<h2>报价里常被省略的项</h2>
<p>一是开通费。二是地址费（部分方案把地址单独计价）。三是超流量后的加收单价。四是续费价格。四项都不会写在显眼的月费旁边。</p>
<p>把四项补进「首月总支出」和「第二年总支出」两个口径，报价才真正可比。只看月费，容易被低价吸引然后在别处补回来。</p>

<h2>怎么判断一个报价是否合理</h2>
<p>三步：同参数问三家，取中间区间；把一次性费用摊进首月；确认续费价。三步之后，如果某家明显低于区间，就问它在独享、带宽、运维三项里让步了哪一项。</p>
<p>愿意说明的，可以谈；说不清的，按风险最高预估。这条判断规则在任何地区的采购里都适用。</p>
